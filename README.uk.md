## Що робить модуль

Модуль автоматично отримує й оновлює безкоштовні SSL-сертифікати від [Let's Encrypt](https://letsencrypt.org/) для веб-інтерфейсу Dzvin PBX. Після налаштування HTTPS-сертифікат випускається автоматично й подовжується за розкладом — ручні дії не потрібні.

## Способи перевірки

### HTTP-01 (за замовчуванням)
Класичний спосіб: Let's Encrypt перевіряє володіння доменом HTTP-запитом до вашого сервера на порт 80. Достатньо вказати доменне ім'я й зберегти налаштування.

**Вимога:** порт 80 має бути доступний з інтернету. Модуль відкриває його тимчасово на час перевірки й одразу закриває.

### DNS-01
Випуск сертифіката через API вашого DNS-провайдера. Порт 80 відкривати не потрібно — працює за файрволами, NAT і в закритих мережах. Також підтримує **wildcard-сертифікати** (`*.domain.com`).

**Підтримувані провайдери:** Cloudflare, Amazon Route53, GoDaddy, DigitalOcean, Hetzner, OVH, Namecheap, Azure DNS, Vultr, DuckDNS, Linode, INWX, DreamHost, deSEC, PowerDNS, ISPConfig, Google Cloud DNS та довільний власний провайдер (скрипти acme.sh). З постачання прибрано хуки DNS-провайдерів, що працюють у РФ.

**Налаштування:** виберіть DNS-01 у списку способів перевірки, вкажіть DNS-провайдера, введіть облікові дані API й збережіть.

## Як це працює

1. Встановіть модуль із маркетплейсу Dzvin PBX
2. Вкажіть доменне ім'я в налаштуваннях модуля
3. Виберіть спосіб перевірки (HTTP-01 або DNS-01)
4. Для DNS-01 — виберіть DNS-провайдера й введіть облікові дані API
5. Натисніть «Зберегти» — модуль запитає сертифікат у Let's Encrypt, хід виконання показується в реальному часі
6. Отриманий сертифікат автоматично застосовується до веб-інтерфейсу Dzvin PBX

Автоматичне оновлення виконується 1-го і 15-го числа кожного місяця.

## Вимоги

- Dzvin PBX версії **2024.1.114** або вище
- Доменне ім'я, що вказує на вашу АТС (A-запис)
- **Для HTTP-01:** порт **80**, доступний з інтернету
- **Для DNS-01:** облікові дані API вашого DNS-провайдера

## Технічні деталі

Модуль використовує [acme.sh](https://github.com/acmesh-official/acme.sh) як ACME-клієнт — поширений bash-скрипт без залежностей, що підтримує ACME v2 і понад 150 DNS-провайдерів.
